## 第二阶段：核心系统实现

### TASK-005 RecipeManager（食谱数据管理） `P0`
- [x] 加载并解析 `recipes.json` 和 `ingredients.json`
- [x] 提供接口：`get_recipe(id)`、`get_unlocked_recipes()`
- [x] 实现解锁逻辑：根据评价阈值解锁新菜谱

### TASK-006 客人系统（CustomerSystem） `P0`
- [x] 创建 `customer.tscn` 预制体（Sprite2D + 对话气泡）
- [x] 实现 `Customer` 类：type、patience、symptoms、request
- [x] 实现客人生成器：按概率生成 normal / sick / special 三类客人
- [x] 实现耐心倒计时：超时则离开并扣评价

### TASK-007 烹饪系统 — 力度条核心逻辑（CookingSystem） `P0`
- [x] 实现 `cooking_system.gd`：力度条小游戏控制器
- [x] **指针动画**：用 `Tween` 或 `_process` 驱动指针在半弧上来回摆动
- [x] **区域判定**：点击时读取指针角度，对照完美/良好/一般/错误区域，返回本轮得分
- [x] **多轮流程**：按菜谱 `steps` 数组顺序执行每轮，全部结束后汇总
- [x] **评级输出**：平均分 ≥90 完美 / ≥70 成功 / ≥40 一般 / <40 失败
- [x] **超时处理**：单轮超过 `time_limit` 自动记 0 分并进入下一轮
- [x] **难度参数驱动**：从菜谱 step 配置读取 `needle_speed` 和 `perfect_zone_size`

### TASK-008 评价系统（RatingSystem） `P1`
- [x] 实现 `rating_system.gd`
- [x] 根据烹饪结果更新 rating 和 customer_count
- [x] 触发解锁检查（评价达到阈值时通知 RecipeManager）
- [x] 提供评价历史记录接口

### TASK-009 每日流程控制（DayManager） `P1`
- [x] 实现 `day_manager.gd`
- [x] 每日开始：生成客人队列、选取每日推荐菜品
- [x] 每日结束：结算评价、触发自动存档、过渡到下一天
